# Neumatrans Workshop Management Dashboard

## Overview

The **Neumatrans Workshop Management Dashboard** is a web application designed to efficiently manage the operations of the Neumatrans workshop. It allows users to handle customers, vehicles, repairs, and invoicing in a streamlined manner. The system also includes automated email notifications to keep customers informed about their repair status and AI-powered statistical insights to optimize business decisions.

This application is specifically developed for **Neumatrans**, ensuring it meets their operational needs. However, a demo version is available for those who want to explore its functionalities.

## Technologies Used

- **Backend:** Laravel
- **Frontend:** Vue.js with Inertia.js
- **Database:** MySQL
- **Deployment:** Docker (optional)

## Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/your-repo/neumatrans-dashboard.git
   ```
2. Navigate to the project directory:
   ```sh
   cd neumatrans-dashboard
   ```
3. Install frontend dependencies:
   ```sh
   npm install
   ```
4. Install backend dependencies:
   ```sh
   composer install
   ```
5. Start the development server:
   ```sh
   npm run dev
   ```
6. Run the backend server:
   ```sh
   php artisan serve
   ```
   Or, if using Docker:
   ```sh
   sail up
   ```
